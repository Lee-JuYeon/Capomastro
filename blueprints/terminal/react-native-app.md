npx @react-native-community/cli init creates a new React Native project with TypeScript template.
Requires Xcode (iOS) and/or Android Studio (Android) installed for device builds.

```json
[
  { "action": "shell", "cmd": "npx @react-native-community/cli@latest init {name} --template react-native-template-typescript --skip-install false", "cwd": "{outputDir}", "timeout": 120000 }
]
```
